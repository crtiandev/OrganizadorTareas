# 📋 Planificador de Tareas 

> Aplicación web desarrollada para la gestión eficiente de tareas y control de tiempos.

---

## 🚀 1. Descripción del proyecto
El **Planificador de Tareas** es una solución interactiva que permite a los usuarios organizar sus actividades diarias por secciones, y registrar nuevas tareas.
